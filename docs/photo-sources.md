# Fuentes y uso de fotografías

Las 12 fotografías actuales son referencias de Pexels, seleccionadas para visualizar el diseño. El registro verificable está en [photo-sources.json](photo-sources.json): página original y autor de cada imagen, URL de descarga, fecha, dimensiones y SHA256 del archivo descargado.

Se consultó la [licencia oficial de Pexels](https://www.pexels.com/license/) el29/10/2026. Permite descargar y utilizar las fotografías y modificarlas, sujeto a sus restricciones; no se implica respaldo de personas o marcas a la institución. Se incluyen créditos visibles aunque la atribución no sea obligatoria bajo esa licencia. No se redistribuyen como colección de stock ni se venden sin modificar.

Las fotos de personas no se presentan como miembros, pacientes o personal del Círculo; habitaciones y salón no se identifican como instalaciones reales. Los epígrafes y alt mantienen ese contexto. Las imágenes locales se sirven desde el sitio y no incorporan tracking ni API de terceros.

La revisión de licencias es específica de estos archivos: al sustituir una imagen, confirmar su fuente y derechos. El material institucional necesita identificación y permisos propios; Pexels no aporta validación de instalaciones o servicios.
